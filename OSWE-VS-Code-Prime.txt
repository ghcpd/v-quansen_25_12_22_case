## ✅ Fix summary & results

**What I found**
- The test failures were caused by two issues:
  - Calling `.lower()` on a possibly `None` email in api_client.py (`normalize_profile`) causing AttributeError.
  - Indexing into `interests[0]` in data_processor.py (`summarize_user_profile`) causing IndexError when the list was empty.

**What I changed**
- api_client.py
  - Replaced unsafe `.lower()` call with a safe normalization:
    - If email is a non-empty string, use `email.lower()`.
    - Otherwise, use the fallback `"unknown@example.com"`.
- data_processor.py
  - Avoided indexing directly into `interests[0]`. Now:
    - `primary_interest` is `interests[0]` if present, else `None`.
  - Made city extraction slightly more defensive (ensure first address is a dict).
